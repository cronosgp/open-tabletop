Enable **Match setup → Advanced match options → Next prepared match: Reanimation Protocols** for a prepared or saved-list training match. Both LAN players must agree. This implements the faction effect for 26 source-sized single-profile unit identities: **Warriors, Immortals, Flayed Ones, Skorpekh Destroyers, Scarab Swarms, Canoptek Wraiths, Lokhust Destroyers, Lokhust Heavy Destroyers, Ghost Arks, Canoptek Doomstalkers, Doomsday Arks, Monoliths, Triarch Stalkers, Ophydian Destroyers, Annihilation Barges, Canoptek Macrocytes, Canoptek Reanimators, Canoptek Spyders, Canoptek Tomb Crawlers, Doom Scythes, Convergence of Dominion, Cryptothralls, Night Scythes, Obelisks, Tesseract Vaults and Tomb Blades**. Warrior/Immortal bodyguard attachments remain admitted. The Silent King's mixed Szarekh/Menhir unit remains blocked. This does not certify a complete current Necron army or detachment.

## Player flow

1. Command entry snapshots living models as return anchors. Battle-shock resolves before this end-of-phase ability; being battle-shocked does not itself prevent it.
2. The active Necron controller chooses the order of eligible living units. Every unit activates, including intact units. The host rolls one D6, mapped to D3 as 1–2 / 3–4 / 5–6. If a living battlefield Reanimator is within 3 inches, one additional D6 maps to a separate D3 and is added to that activation; the same Aura never adds more than one D3. The Aura roll happens after any allowed base-roll choice.
3. The shared D3 budget heals the single admitted wounded survivor first. Remaining wounds provide return attempts, capped by the unit's missing models. Attached healing and returns commit together after preview; when there are no return attempts, healing commits immediately. The controller chooses original destroyed model IDs. IDs, weapons and enhancements remain on the original model record.
4. Use X/Z coordinates or right-click the board to preview positions. **Suggest return positions** is a convenience search, not proof that all possible positions have been considered. Purple models are previews; their wounds and objective control are unchanged.
5. Confirm after all available attempts are assigned. Alternatively explicitly declare that a selected model cannot be placed; it stays destroyed and the declaration is recorded. The engine validates proposed positions but does not mathematically prove an impossibility declaration. Reset clears the draft while retaining the original roll. Confirming the last unit completes Command and resolves control without repeating Battle-shock or CP gain.

Returned bases must fit fully on the board, avoid living and staged bases and blocked terrain, remain within 2 inches of a surviving Command-entry anchor and within 9 inches of every living unit member, and leave the final unit coherent. Newly returned models cannot extend the anchor chain. Only enemy units engaged before this return may be engaged by it. This is setup: a corpse's former position does not create a movement path requirement.

Unused healing and declared placement failures are reported. There is no extra D3 carry-over and no later activation of the same unit in that Command phase. The model choice preserves different equipment rather than always reviving the lowest ID automatically.

## Authority and recovery

Implementation ID: `reanimation-core-profiles-2026-10-31-v8`. The boolean setup option is frozen in the manifest and saved-list options; disabled matches retain their previous identity. Old saves default to disabled, and conflicting save or peer flags are rejected. Version v8 adds Canoptek Reanimator's source-listed Reanimation, model-only Feel No Pain 4+, and one-per-unit Nanoscarab Aura healing; earlier enabled saves require their matching implementation rather than silently migrating pending healing.

The pending queue, original roll, budget, phase-entry anchors, pre-return engagement, chosen positions and declarations are serializable public state. The server validates player, phase, revision, unit, model, budget and geometry; clients send choices, never dice or wound totals. Unrelated gameplay commands and tactical movement guides are blocked while a decision is pending. Save/load and authenticated rejoin after a fresh host-process restart preserve the draft and RNG, and do not reroll.
