# Intercessor Hail of Bolts

Enable **Match setup → Advanced match options → Next prepared match: Intercessor Hail of Bolts** before a prepared or saved-list match. Both LAN players must agree. In Play, open **Plan attacks across targets**, select a visible enemy with the **Hail of Bolts** picker, assign weapons and confirm. **Do not use** preserves the ordinary attack pool. Direct single-target shooting does not silently choose the ability.

The verified source is the [June 2026 Space Marine datasheet cards](https://assets.warhammer-community.com/eng_04-06_warhammer40k_new40k_armageddon_spacemarines_datasheet_cards-hcuj9cke0r-h2rfuky1yw.pdf), PDF page 5. In the unit owner's Shooting phase, bolt rifles assigned to the chosen visible enemy gain two attacks each. Splitting other rifles onto other targets does not grant those rifles the bonus. Grenade launchers, plasma, pistols, melee and other units do not inherit it. Existing range, visibility, movement, weapon-ownership and targeting restrictions still apply to each actual attack. Ability target visibility can come from any living model in the unit.

Only canonical pure Intercessor squads and the explicit starter rifle inventory are admitted. Varied-equipment saturation/focused profiles retain their rifle identity; the legacy default maps to the pinned rifle. This does not add arbitrary renamed weapons or propagation through mixed Leader attachments. The pinned provisional `target-elimination` slot is recorded as superseded by the verified `hail-of-bolts` capability; its generic imported +2-A DSL is never executed.

The bonus is added per source weapon before random attack generation and pooling, alongside existing Rapid Fire/Blast bonuses. Eligible and ineligible sources cannot merge under misleading ability metadata. The server freezes the chosen target and expanded pools before dice. Preview never edits the source profile. A completed attack records the target in `last_attack`, the event notice and journal. Other attack decision windows retain the frozen pool; changing visibility or casualties later does not recalculate the declared ability. A unit that already shot cannot select another target or regenerate attacks.

Capability ID: `intercessor-hail-of-bolts-v1`. The registry, manifest, saved-list setup and save configuration preserve it. Saves made before the option restore disabled. Draft saves preserve the chosen target; pending attack saves preserve expanded generation and RNG. Conflicting save/peer options are rejected. Selected units display the ability, and the plan previews its target and bonus before confirmation.

Only the ability effect is adopted from that source. Starter unit sizes, weapons and costs remain the project's pinned reference data, including existing provisional profile mechanics. This does not certify the later October Codex or complete legal lists. See [Track A](../project/track-a.md) and [Oath source/version assessment](oath-of-moment.md).
