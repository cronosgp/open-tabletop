# Shooting at engaged Monsters and Vehicles

The current Wahapedia 11th-edition Core Rules, June 2026 rules revision, state in §17.03 that an engaged enemy MONSTER/VEHICLE can be selected as a ranged target during the attacking player's own Shooting phase. BLAST attacks cannot target it. Attacks against it subtract 1 from the Hit roll, except CLOSE-QUARTERS attacks made by a unit engaged with that target. [Current Core Rules](https://wahapedia.ru/wh40k11ed/the-rules/core-rules/) were checked on 26 October 2026.

## Target and shooter boundaries

- An unengaged shooter may target an engaged enemy MONSTER/VEHICLE only during its controlling player's own Shooting phase.
- A shooter that is already engaged still needs an eligible Close-quarters shooting type. It can target only enemy units its own unit is engaged with.
- BLAST cannot target an engaged unit, including when the target has MONSTER or VEHICLE.
- The target's -1 Hit modifier is waived only when the attack uses a CLOSE-QUARTERS weapon and the attacking unit is engaged with that target. Other Hit modifiers continue through the shared cap.
- This target exception does not apply to out-of-phase shooting. A separate rule may allow that shooting, but §17.03 does not grant access to an engaged MONSTER/VEHICLE target outside the attacking player's own Shooting phase.

The shared attack planner enforces these boundaries in target selection and attack preparation. This remains a bounded core-rule slice: the full set of out-of-phase shooting effects and every MONSTER/VEHICLE datasheet interaction are not certified.
