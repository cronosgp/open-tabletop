# Certifying contact approach exceptions

The contact validator now accepts some previously rejected “if possible” exceptions. It does not treat failure to find a path as evidence that no path exists. A threshold is waived only when a relaxed movement/placement problem is proved impossible.

The baseline remains [11e Core Rules](https://wahapedia.ru/wh40k11ed/the-rules/core-rules/), §§11.04, 12.03 and 12.08. Charges check the 1-inch approach and engagement approach independently. Proving that 1 inch is impossible never waives a reachable engagement requirement. Other final conditions, including coherency, declared charge targets, closer movement and retained engagements, still apply.

## Terrain certificates

The host computes horizontal route bounds on a visibility graph around rectangular obstacles in a relaxed flat configuration space. Unions of inner expanded rectangles approximate circular-base clearance from below, including rounded corners. Fixed same-height Surge blockers use 16 stacked inscribed rectangles; the focused regression confirms a stronger lower bound than the earlier 8-slice approximation while remaining below the analytic circle route. For an enemy approach, the bound also adds the minimum vertical movement needed to enter the 5-inch engagement-height band. Rules that ignore vertical movement omit this term. The goal square contains the target's entire approach disk. Enemy bases and battlefield bounds are omitted from the horizontal calculation, making it easier to reach the goal than in actual play.

If even this shorter relaxed route exceeds the move's original full allowance, with a numerical margin, the host has a valid obstruction certificate. It never uses the remaining allowance after a player's detour as evidence of impossibility. All live models in every eligible target unit are considered.

For example, on the current exercise board, a model at `(-5, 0)` charging a target at `(5, 0)` with a 10-inch roll can route above the central block and finish around 1.9 inches away. The host now certifies that approaching within 1 inch is impossible, while still requiring engagement.

## Coherency certificates

Each friendly model has a relaxed reachable domain based on its origin and full movement allowance. Base-contact locks are preserved. Non-charge moves also retain each model's required enemy engagements. The focused model's domain is constrained to the approach being checked.

The analysis represents each model's conservative reachable elevation domain as a union of narrow intervals around legal endpoint heights. It includes ground and eligible upper-surface heights whose base-fit bounds overlap that model's relaxed XY box and whose vertical change fits its full movement allowance. For an endpoint on a different elevated floor, the certificate checks a lower bound through the destination floor's listed access zone: distance from the origin to the zone, from the zone to the relaxed endpoint box, and the minimum vertical travel. A ground endpoint from an elevated start uses the union of eligible elevated access zones, preserving routes that first descend through a lower intermediate floor; an endpoint on the starting floor at the same elevation needs no access transition. The zone union is prepared once per model's surface domain, and each check stops when one zone fits; this removes repeated preparation but has no measured general runtime result. These access checks are lower bounds only. Other walls, blockers and route feasibility remain relaxed, and invalid access data or starting geometry falls back to the continuous movement interval instead of becoming proof. For an enemy-target root, the focused model's domain is intersected with the target's 5-inch engagement-height band. Marker-objective range goals use the same 5-inch vertical band; terrain-objective goals and horizontal closest-distance goals do not. Models that must retain an engagement intersect their domain with the union of the retained enemy models' 5-inch height bands; invalid or missing retained heights leave that constraint open. Rules that ignore vertical movement retain an unbounded domain. Pair checks use the minimum gap across both models' interval unions: a pair is rejected when even that minimum exceeds 5 inches, and it can form a 2-inch neighbour edge only when both horizontal and vertical separation may fit. This tightens the height relaxation without certifying that a supported surface route exists.

The analysis checks circular constraints, the 9-inch horizontal diameter bound, and whether a connected 2-inch-neighbour graph can exist. It can subdivide remaining domains to rule out arrangements. Teammates are allowed to rearrange throughout their full reachable domains; they are not frozen at either their origins or submitted destinations.

An example now supported is a pile-in with a locked anchor and another model that must retain a different enemy. If the middle model cannot reach engagement without disconnecting that formation, a smaller closer move can be accepted. Pairwise domain bounds measure rounded-rectangle terrain goals exactly against disk or rounded-rectangle domains, avoiding the looser single circumscribing disk. When a target has multiple candidate models, each search root now computes these bounds for its own goal region; a nearer alternative no longer weakens every candidate's coherency bound. These remain lower bounds for impossibility proofs.

For obstructed movement, the route lower-bound query also accepts the relevant maximum distance. If the nearest point in the goal box is already farther away than that budget, its Euclidean distance is returned immediately: obstacles can only increase the true route length, so building the visibility graph cannot change the certificate decision. Otherwise, a rectangle is omitted only when any route touching it would already exceed the budget. The remaining obstacle vertices are rebuilt for the filtered union, and A* stops once the smallest open estimate exceeds the certificate threshold. A controlled detour fixture filtered eleven remote rectangles and 44 of 48 obstacle corners; it returned a 10.5146-inch lower bound above the 10.02-inch certificate threshold, while the complete relaxed path measured 10.5342 inches. Malformed obstacles remain. These are correctness-preserving, fixture-level work reductions, not general wall-clock claims.

## Limits and records

The search is deterministic and bounded to 1,024 domain boxes, with padded geometry and a minimum box width. Exhausting the bound or reaching an unresolved boundary means **unknown**, so the requirement remains enforced. These are certificates of impossibility, not a complete pathfinding or squad-layout solver. Enemy-base blockades, some obstacle layouts, and complex combined arrangements may still be rejected despite being legal. Contact placement validates per-model elevation and vertical travel against the default central ruin. Separately, the movement pathfinder handles bounded multi-obstacle routes on one same-height supported surface, including the tested elevated floor. The certificate adds only the unavoidable vertical cost for an enemy approach; it does not enumerate supported surface transitions or prove that an elevated route exists. FLY terrain is omitted from its obstacle relaxation to avoid rejecting routes that can use an elevated surface. Full multi-squad fight queues remain separate work. Original obstacle fixtures explicitly select the legacy map.

Accepted certificates are stored in `last_contact_proofs` and replicated in authoritative snapshots. The event log identifies the model, threshold, and reason. The match implementation identifier changed to `11e-3d-integration-v7`; older clients cannot join this implementation.
