# Rhino — source-bounded local scope

This closes the shared-book 11th-edition local datasheet scope for [Rhino](https://wahapedia.ru/wh40k11ed/factions/space-marines/Rhino), source book 000000139, datasheet 000002723. The page is under the Space Marines App 2.8.1, updated October 2026; it was checked alongside the verified local Data Export snapshot on 28 October 2026. The checked context is the common 40K datasheet and points view, with no Chapter selected; this scope does not certify Boarding Actions or other mode-specific lists.

## Implemented and checked

- The source composition is one model. Roster prices are 70 points for each of the first three copies and 80 for the fourth and later copies. The local catalog currently caps Rhino at three; admission, saved-list cost summaries and builder previews retain the fourth-copy source tier.
- The source says “Use model”; runtime uses a labelled 120 mm circular proxy, not exact model geometry. The source characteristics, keywords and default Storm Bolter and Armoured Tracks profiles are retained.
- The transport carries 12 ADEPTUS ASTARTES INFANTRY spaces and excludes GRAVIS, JUMP PACK and TERMINATOR models. Army Preparation offers a reversible no-cost Hunter-killer Missile, retaining One Shot. Firing Deck 2 and Deadly Demise D3 are bound from the source.
- Veiling Smoke lets this Rhino use Smokescreen for 1 fewer CP once per phase, without preventing another unit from using Smokescreen that phase. Focused checks cover separate Rhino uses, current-catalog admission for both players, the local copy ceiling and source-tier pricing.
- Profile, optional weapon, Veiling Smoke, transport, destruction and roster checks passed in the focused offline verification recorded in the [machine-readable source and hash audit](marine-rhino-audit.json).

## Limits

The 120 mm footprint is only a game proxy because the source gives no fixed vehicle base. The three-copy catalog ceiling is local and does not establish full army legality. Chapter-book content, network behavior, complete-match certification and human playtesting remain outside this scope; network validation is deferred to final integration.
