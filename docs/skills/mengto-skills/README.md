# Selected MengTo/Skills for this project

This folder records the upstream source and license for the project-specific skill adaptations in sibling folders. The upstream repository contains many web, Three.js, and unrelated workflows; only the skills useful for this Godot tabletop game's visual design loop are included.

## Included adaptations

- `../design-first-ui-prompting/SKILL.md` — turn a game-screen request into a concrete visual and interaction specification.
- `../workflow-progress-screenshots/SKILL.md` — inspect real Godot captures through visual changes.
- `../workflow-score-to-target/SKILL.md` — evaluate visual work against a user-requested numeric target.

Source: [github.com/mengto/skills](https://github.com/mengto/skills), upstream `main` as inspected on 2026-10-17. The source repository describes its skills as portable, procedural `SKILL.md` playbooks. These files are adapted for Godot and the project; they are not a mirror of the upstream collection.
